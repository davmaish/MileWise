# MileWise Design System

## Design Philosophy

MileWise follows a modern automotive dashboard aesthetic built around clarity, consistency, and readability.

The application prioritizes:

- Dark UI
- High information density
- Strong visual hierarchy
- Consistent spacing
- Reusable design tokens

The tab bar is customized through Expo Router rather than a custom navigation component.
